# 分层架构

四层单向依赖，禁止反向包含。media 模块默认不编译（`OPENGUI_MEDIA_FFMPEG`/`OPENGUI_MEDIA_OPENCV`，默认 OFF）。

```
apps   Demo 可执行（opengl_ui_demo）
media  media/ffmpeg（VideoView，链接 FFmpeg）media/opencv（ImageView，链接 OpenCV）——可选
ui     ui_ui 静态库（Widget 基类 → 控件树/布局/样式，M1+）
gl     ui_gl 静态库（GLFW 窗口、Renderer 2D 矩形管线、Texture/stb_image、Font/stb_truetype、GLAD）
core   ui_core 静态库（纯 C++：math/log/version，禁止 include GL/媒体头文件）
```

依赖方向：media → ui → gl → core。3rdparty 前缀由顶层 CMake 按架构推导。
